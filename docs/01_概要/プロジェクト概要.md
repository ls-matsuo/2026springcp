# プロジェクト概要

## 要件定義

- PHP＋SQLite でメールフォームを作成する。
- **入力項目はニックネーム、メールアドレス。**
- **DB は 1 テーブルに投稿内容（ニックネーム、メールアドレス、登録日時）を格納する。**
- ニックネームおよびメールアドレスをユニークに設定し、重複エラーを確認画面で出す。
- **ニックネームの重複チェックは、完全一致だけでなく半角アルファベットの大文字小文字違いも対象とする。**
- DB には他のテーブルも入れるので影響しないようにする（テーブル名に接頭子を付ける）。
- CSV ダウンロード画面は不要。
- 上記以外の特殊な設問仕様（分岐、アニメーションなどの演出、1 設問ごとのページ遷移等）はなし。
- 申込み者に自動返信メールを送る。
- **キャンペーンフォームはデザインを作ってお渡しする。**
- **弊社のリポジトリに制作データを格納いただく。**
