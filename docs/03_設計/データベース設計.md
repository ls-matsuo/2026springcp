# データベース設計

## 概要

- **RDB**: SQLite（ファイル: `entry/includes/db/2026springcp.db`）
- **テーブル**: `entries`
- **カラム**: email, nickname, created_at, member_id, plan, matched

## テーブル定義: entries

| カラム名 | 型 | 制約 | 説明 |
|----------|-----|------|------|
| id | INTEGER | PRIMARY KEY AUTOINCREMENT | 主キー |
| email | TEXT | NOT NULL | フォームで入力されたメールアドレス |
| nickname | TEXT | NOT NULL | フォームで入力されたニックネーム |
| created_at | TEXT | NOT NULL | エントリー日時 |
| member_id | TEXT | NULL | ETL処理で使用 |
| plan | TEXT | NULL | ETL処理で使用 |
| matched | INTEGER | NULL, DEFAULT 0 | ETL処理で使用 |

- **重複チェック**: 送信時にサーバーサイドで正規化（小文字化・全角半角正規化・トリム）して比較。DB にはトリムだけ適用し、ユーザーが入力した値をそのまま保存。

## スキーマ定義ファイル

- **ファイル**: `containers/database/schema.sql`
- 初回構築時やスキーマ確認時にこの SQL を実行してテーブルを作成する。
